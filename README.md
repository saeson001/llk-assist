# 连连看助手（Android）

识别连连看游戏棋盘，自动找出**当前可以连线消除的方块对**（连线最多折两次，可绕棋盘外），
在悬浮窗中以"相同编号圆牌"标出配对方块；可选通过无障碍服务**自动点击消除**、可选 AI 视觉接口复核。
全部识别在本机完成；AI 调用为可选功能，走用户自配的接口。

对应游戏：绿色棋盘、方块贴图摆放在绿色衬底上的连连看玩法，分辨率自适应，支持有空槽的不规则棋盘与障碍物。

## 安装与使用

1. 从 [Releases](../../releases) 下载 `llkzs_<版本号>.apk`（Android 8.0 及以上）并安装。
2. 打开应用，按顺序完成授权：
   - 悬浮窗权限：允许"显示在其他应用上层"。
   - 无障碍服务：用于自动点击消除。
   - 文件权限：授权"所有文件访问"后日志/缓存位于存储根目录 `LLKZS`，否则在应用目录下。
   - 点"启动"，允许录屏。
3. 屏幕出现小控制面板（可拖动）：
   - **识别**：立即抓屏分析一次。
   - **选区**：拖动框选棋盘区域，识别只分析框内（更准）；轻点恢复全盘。
   - **自动消**：开关。开启后进入状态机：识别 → 规划（每轮最多 10 对）→ 连续消除 → 重新识别循环；
     校准过暂停/继续按钮则走"暂停冻结→继续→消除"流程，否则直接模式。状态实时显示在面板文字栏。
   - **校准**：分别点一次游戏里的"暂停""继续"按钮，保存坐标供自动消的暂停流程使用（可选）。
   - **数字:开/关**：显示/隐藏编号圆牌（默认关）。
   - **日志**：一键分享当天运行日志（微信/QQ 等任意方式发出，用于问题排查）。
   - **退出**：关闭录屏与悬浮窗。
4. 每对可消方块的两个方块上会显示相同编号的圆牌，点掉这两块即可消除。

## AI 接口（可选）

编辑 `LLKZS/config.json`（首次启动自动生成模板）：

```json
{
  "aiEnabled": true,
  "aiBaseUrl": "https://你的OpenAI兼容接口/v1",
  "aiApiKey": "你的Key",
  "aiModel": "支持图片输入的模型名"
}
```

开启后识别时会把棋盘截图发给该模型，AI 判断哪些配对可连、哪些同图案但不可连（含原因），
与本地识别合并显示，全过程写入日志。响应为严格 JSON，解析失败只记日志不影响本地提示。

## 代码结构

```
core/src/main/java/com/llk/assist/core/     纯 JVM 核心模块（可在 PC 上单测）
    BoardDetector.kt       绿色棋盘定位 -> 非绿连通域=方块 -> 行列密度收拢 -> 等差格点拟合
                           （支持空槽、选区、障碍物 BLOCKED；边距剖面法计算方块视觉中心）
    TileClassifier.kt      内容掩码 IoU + 内容区 RGB 相关 + 直方图 -> Otsu 阈值 -> 聚类
    OnetSolver.kt          0/1/2 折连线路径搜索 + 整盘贪心序列求解
app/src/main/java/com/llk/assist/
    MainActivity.kt        权限引导与启动入口
    CaptureService.kt      前台服务：抓帧 -> 核心算法 -> 悬浮窗 -> 自动消状态机
                           （幻影帧过滤、稳定门、代际令牌防并发重入、每轮 10 对上限）
    HintOverlay.kt         编号圆牌绘制层（不可触摸）
    RegionSelectView.kt    选区层
    TapCaptureView.kt      校准取点层
    AiClient.kt            AI 视觉接口
    LlkDir.kt / LlkLog.kt  工作目录与日志
    GameWatchService.kt    无障碍服务：手势点击（主线程派发）
```

### 关键机制

- **幻影帧过滤**：消除/填充动画中的错帧会识别出错误网格，按"本局主流网格签名计数"拒绝。
- **稳定门**：规划前对棋盘区做两次采样（间隔 400ms），差异 <8% 才允许规划，避免在掉落/填充动画中建模。
- **代际令牌（epoch）**：自动消的全部异步回调持有发起时的代数，开关切换/新一轮开始使旧代数作废，
  根治"两条规划/执行流并发、同一坐标被点两次"的重入问题。
- **每轮序列上限 10 对**：游戏在消除约 1/3 时会重新填充，限制长序列在重填后全部过期。

## 构建环境（本机）

- JDK 17、Android SDK、Gradle wrapper（发行包走阿里云镜像，依赖阿里云 Maven）

```bat
set JAVA_HOME=C:\Java\jdk-17
cd /d D:\testcode\llk-assist
gradlew.bat assembleDebug
gradlew.bat :core:test
```

APK 输出：`app\build\outputs\apk\debug\llkzs_<版本号>.apk`。
注意：交付一律用 debug 签名包（release 块也已配置同一签名）；更新安装后需重新开关一次无障碍服务。

## 已知限制

- 针对绿色棋盘皮肤调参；换其他配色皮肤需调 `BoardDetector.isGreen`。
- AI 接口需要能访问所选服务端；响应质量取决于模型对游戏截图的理解能力，日志中可核对。
- 自动消依赖无障碍手势，部分机型的"防误触/安全弹窗"可能拦截无障碍点击。
